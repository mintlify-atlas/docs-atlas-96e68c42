## Overview

Once you've completed all six data sections and uploaded all required documents, you're ready to finalize your evaluation. This is the final step before your information is submitted for official review.

<Warning>
Finalizing your evaluation is irreversible. Make sure all information is accurate and complete before submitting.
</Warning>

## Prerequisites

Before you can finalize, the system verifies:

<AccordionGroup>
  <Accordion title="All Data Sections Complete (6/6)">
    ✓ Personal Data
    ✓ Family Data
    ✓ Academic Data
    ✓ Career Trajectory
    ✓ Economic Data
    ✓ References
  </Accordion>

  <Accordion title="All Required Documents Uploaded">
    **Permanencia (5 documents):**
    ✓ Birth Certificate
    ✓ Official ID (INE)
    ✓ Proof of Address
    ✓ Proof of Studies
    ✓ Proof of Income

    **Nuevo Ingreso (6 documents/items):**
    ✓ Birth Certificate
    ✓ Official ID (INE)
    ✓ Proof of Address
    ✓ Proof of Studies
    ✓ Military Service Card
    ✓ Proof of Income OR Motive Description
  </Accordion>
</AccordionGroup>

<Info>
The "Finalize" button only appears when ALL requirements are met. If you don't see it, check which sections or documents are still incomplete.
</Info>

## How the System Checks Completion

### Permanencia Validation

The system runs this check:

```javascript
if (TotalCaptura === 6 && TotalCargaPerma === 5) {
  const ListoRevision = true;
  // Finalize button becomes available
}
```

**Where:**
- `TotalCaptura` = Number of completed data sections (must be 6)
- `TotalCargaPerma` = Number of uploaded required documents (must be 5)

### Nuevo Ingreso Validation

The system runs this check:

```javascript
if (TotalCaptura === 6 && TotalCargaNI === 6) {
  const ListoRevision = true;
  // Finalize button becomes available
}
```

**Where:**
- `TotalCaptura` = Number of completed data sections (must be 6)
- `TotalCargaNI` = Number of documents/items (5 documents + 1 motive OR 6 documents = 6 total)

<Note>
The system automatically detects your evaluation type and applies the correct validation.
</Note>

## Finalizing Your Evaluation

<Steps>
  <Step title="Access Your Evaluation Dashboard">
    Make sure you're viewing your evaluation at:
    ```
    /evaluacionvLife/evaluacionView/[encrypted_evaluation_id]
    ```

    Verify that the page shows:
    - All 6 data sections complete
    - All required documents uploaded
    - Progress at 100%
    - "Listo para Revisión" (Ready for Review) status
  </Step>

  <Step title="Locate the Finalize Button">
    The finalize button should be visible on your dashboard.

    It may be labeled:
    - "Finalizar Evaluación"
    - "Enviar a Revisión"
    - "Concluir Captura"

    <Info>
    If you don't see a finalize button, the system has detected incomplete requirements. Check all sections and documents.
    </Info>
  </Step>

  <Step title="Read the Confirmation">
    When you click finalize, you'll see a confirmation dialog:

    - Warning that this action is final
    - Notice that you cannot edit after finalization
    - Confirmation that all information is accurate
    - Option to cancel or proceed
  </Step>

  <Step title="Confirm Finalization">
    If you're certain everything is correct:
    - Click "Yes" or "Confirm" or "Finalizar"
    - The system processes your submission
    - Wait for the confirmation message
  </Step>

  <Step title="Receive Confirmation">
    Success message: **"Evaluación Finalizada"**

    You'll be redirected to your profile page at `/auth/profile`

    The system records:
    - Evaluation ID
    - Finalization date and time (`finalizadoFecha`)
    - Sets evaluation as finalized in database
  </Step>
</Steps>

## What Happens After Finalization

### Immediate Effects

1. **Evaluation is Locked**
   - You can no longer edit any data sections
   - You cannot change or upload new documents
   - All information is saved as-submitted

2. **Status Changes**
   - Your evaluation status changes to "Finalized"
   - Dashboard shows "En Revisión" (Under Review)
   - Finalization date is recorded

3. **Profile Update**
   - Your profile shows the finalized evaluation
   - You can view but not edit the evaluation
   - Status tracking becomes available

### Review Process Begins

<Steps>
  <Step title="Initial Review">
    Staff reviewers receive notification of your finalized evaluation.

    They will:
    - Verify all required sections are complete
    - Check document quality and validity
    - Review information for consistency
    - Flag any issues or discrepancies
  </Step>

  <Step title="Background Investigation">
    Investigators may:
    - Contact your references
    - Verify employment history
    - Check criminal and legal records
    - Verify educational credentials
    - Conduct financial background checks
    - Visit your residence
    - Interview you or your contacts

    <Info>
    This process can take several weeks to several months depending on complexity and workload.
    </Info>
  </Step>

  <Step title="Review Comments">
    If reviewers have questions or find issues:
    - They may add comments to your evaluation
    - You'll see these comments on your profile
    - You may be asked to provide clarification
    - You may need to provide additional documentation

    <Note>
    Check your profile regularly for any comments or requests from reviewers.
    </Note>
  </Step>

  <Step title="Final Decision">
    After investigation completes:
    - Evaluation is approved or denied
    - You'll be notified of the decision
    - If approved, next steps will be provided
  </Step>
</Steps>

## Common Issues After Finalization

<AccordionGroup>
  <Accordion title="Found an Error After Finalizing">
    **Problem**: Discovered a mistake after submitting.

    **Solutions**:
    - Contact your evaluator or HR immediately
    - Explain the error clearly
    - Provide correct information
    - They may be able to make corrections
    - May require formal correction request

    <Warning>
    Don't wait. Report errors immediately to minimize impact.
    </Warning>
  </Accordion>

  <Accordion title="Reference Not Responding">
    **Problem**: Investigator can't reach a reference.

    **Solutions**:
    - Contact your reference immediately
    - Verify contact information is still correct
    - Remind them to watch for calls
    - If reference is unavailable, notify evaluators
    - May need to provide alternate reference
  </Accordion>

  <Accordion title="Document Rejected After Finalization">
    **Problem**: A document was found to be inadequate.

    **Solutions**:
    - Reviewers will comment on what's needed
    - Obtain the correct or better quality document
    - Submit through the method indicated by reviewers
    - May be able to upload replacement
  </Accordion>

  <Accordion title="Long Wait with No Updates">
    **Problem**: Weeks have passed with no status change.

    **Solutions**:
    - Be patient - investigations take time
    - Check profile regularly for updates
    - After reasonable time (4-6 weeks), inquire politely
    - Contact HR or evaluation coordinator
    - Ask about expected timeline
  </Accordion>

  <Accordion title="Need to Withdraw Application">
    **Problem**: Need to cancel your evaluation.

    **Solutions**:
    - Contact HR or evaluation coordinator
    - Explain reason for withdrawal
    - Follow their withdrawal procedure
    - Get written confirmation if possible
  </Accordion>
</AccordionGroup>

## Best Practices

### Before Finalizing

1. **Review multiple times**: Don't rush the final check
2. **Ask someone to help**: Have another person review for errors
3. **Check against documents**: Verify data matches uploaded documents
4. **Confirm references**: Make sure references are still willing and reachable
5. **Save copies**: Download or screenshot your evaluation before finalizing

### After Finalizing

1. **Document everything**: Keep copies of all documents and your evaluation
2. **Stay responsive**: Check for updates regularly
3. **Be available**: Ensure you can be contacted (phone, email)
4. **Keep references informed**: Let them know investigation is underway
5. **Be patient but proactive**: Balance waiting with appropriate follow-up

## Technical Reference

For developers or technical staff:

### Finalization Process

The system executes:

```javascript
const FinalizarEvaluacion = async (req, res) => {
  const { encryptedData } = req.body;
  const evalID = ncryptObjet.decrypt(encryptedData);
  const finalizadoFecha = Helpers.GetDate();
  
  const dataPacket = {
    evalID,
    finalizadoFecha,
  };
  
  await PoolvLife.query(
    EvaluationvLifeModel.SaveFinalizado, 
    dataPacket
  );
}
```

This:
- Decrypts the evaluation ID
- Records current date/time as finalization date
- Saves to `tbl_dgo_evalfinalizadas` table
- Sets `finalizadoActivo = 1`
- Redirects to profile page

### Database Tables

- `tbl_dgo_evaluaciones` - Main evaluation record
- `tbl_dgo_evalfinalizadas` - Finalization record
- `tbl_dgo_comentarios` - Reviewer comments
- `tbl_dgo_constancias` - Certificates
- Various data tables for each section
