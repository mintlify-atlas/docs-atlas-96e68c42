## Overview

The Career Trajectory API manages employment history and career information. The system handles two distinct evaluation types:

- **Permanencia** (Current Employees): For existing employees undergoing background re-evaluation
- **Nuevo Ingreso** (New Hires): For candidates applying for new positions

Additionally, this API captures information about family members in legal processes and family members working in law enforcement.

## Authentication

All endpoints require authentication via the `isLoggedIn` middleware. Users must have an active session to access these endpoints.

## Get Career Trajectory Data

<api method="GET" path="/TrayectoriaCapturePermanencia/:encyptData" />

Retrieves career trajectory data based on evaluation type.

### Path Parameters

<ParamField path="encyptData" type="string" required>
  Encrypted evaluation data
</ParamField>

### Response

For **Permanencia** (tipoEvalID === 1):

<ResponseField name="dataTrayectoria" type="object">
  Career trajectory data for current employees
</ResponseField>

<ResponseField name="GetAdscripciones" type="array">
  Array of previous department assignments within the organization
</ResponseField>

<ResponseField name="GetFamProceso" type="array">
  Family members with legal processes
</ResponseField>

<ResponseField name="GetFamCorp" type="array">
  Family members in law enforcement/corporation
</ResponseField>

For **Nuevo Ingreso** (tipoEvalID !== 1):

<ResponseField name="dataTrayectoria" type="object">
  Career trajectory data for new hire candidates
</ResponseField>

<ResponseField name="GetEmpleos" type="array">
  Array of previous employment records
</ResponseField>

<ResponseField name="GetFamProceso" type="array">
  Family members with legal processes
</ResponseField>

<ResponseField name="GetFamCorp" type="array">
  Family members in law enforcement/corporation
</ResponseField>

## Save Career Trajectory (Permanencia)

### Request Body

<ParamField body="evalID" type="string" required>
  Evaluation ID
</ParamField>

#### Current Position Information

<ParamField body="trayectoriaDependencia" type="string" required>

</ParamField>

<ParamField body="trayectoriaAdscripcion" type="string" required>
  Current department assignment
</ParamField>

<ParamField body="trayectoriaCargo" type="string" required>

</ParamField>

<ParamField body="trayectoriaGrado" type="string" required>
  Rank or grade level
</ParamField>

<ParamField body="trayectoriaFechaIngreso" type="date" required>
  Date of entry into the organization
</ParamField>

<ParamField body="trayectoriaPromocion" type="date">
  Date of last promotion
</ParamField>

<ParamField body="trayectoriaZonaTrabajo" type="string" required>
  Work zone or area
</ParamField>

#### Job Responsibilities

<ParamField body="trayectoriaPortaArma" type="string" required>
  Whether employee carries a firearm ("Si" or "No")
</ParamField>

<ParamField body="trayectoriaPersonal" type="string" required>
  Whether manages personnel ("Si" or "No")
</ParamField>

<ParamField body="trayectoriaCuantos" type="integer">
  Number of people managed (if applicable)

  Detailed description of job functions

#### Supervisor Information

  Supervisor's name

<ParamField body="trayectoriaPuestoJefe" type="string" required>
  Supervisor's position
</ParamField>

<ParamField body="trayectoriaNumJefe" type="string" required>
  Supervisor's contact number

#### Disciplinary History

<ParamField body="trayectoriaAcusaciones" type="string" required>
  Any accusations ("Si" or "No")
</ParamField>

<ParamField body="trayectoriaProcesos" type="string" required>
  Any legal processes ("Si" or "No")
</ParamField>

<ParamField body="trayectoriaSanciones" type="string" required>

</ParamField>

<ParamField body="trayectoriaProcedimientos" type="string" required>
  Any administrative procedures ("Si" or "No")

## Save Previous Employment

<api method="POST" path="/SaveEmpleos" />

Saves previous employment records for new hire candidates.

### Request Body

<ParamField body="evalID" type="string" required>
  Evaluation ID
</ParamField>

<ParamField body="num" type="string" required>
  Number of employment records being submitted ("1" for single, or count for multiple)
</ParamField>

For single employment (num === "1"):

<ParamField body="empleoEmpresa" type="string" required>
  Company name
</ParamField>

<ParamField body="empleoPuesto" type="string" required>
  Position held
</ParamField>

<ParamField body="empleoDireccion" type="string" required>
  Company address
</ParamField>

<ParamField body="empleoPeriodo" type="string" required>
  Employment period
</ParamField>

<ParamField body="empleoIngreso" type="string" required>
  Salary/income
</ParamField>

<ParamField body="empleoMotivo" type="string" required>
  Reason for leaving
</ParamField>

For multiple employments, all fields above should be arrays.

### Response

<ResponseField name="success" type="string">
  "Se guardaron empleos" - Employments saved successfully
</ResponseField>

## Workflow

### For Permanencia (Current Employees):
1. Get trajectory data
2. Save/Update career trajectory
3. Save department assignments
4. Add family in legal processes (if applicable)
5. Add family in corporation (if applicable)

### For Nuevo Ingreso (New Hires):
1. Get trajectory data
2. Save/Update career trajectory for new hire
3. Save previous employments
4. Add family in legal processes (if applicable)
5. Add family in corporation (if applicable)
