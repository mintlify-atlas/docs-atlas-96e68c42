## Overview

The Economic Data Capture API manages comprehensive financial information for background evaluations. This includes:

- Monthly income and expenses
- Bank accounts
- Credit cards and loans
- Real estate properties (inmuebles)
- Personal property/vehicles (muebles)
- Additional income sources

## Authentication

All endpoints require authentication via the `isLoggedIn` middleware. Users must have an active session to access these endpoints.

## Get Economic Data

<api method="GET" path="/economicosCapture/:encryptedData" />

Retrieves all economic and financial data for a specific evaluation.

### Path Parameters

<ParamField path="encryptedData" type="string" required>
  Encrypted evaluation ID
</ParamField>

### Response

<ResponseField name="DataEconomicos" type="object">
  Main economic data including income and expenses
</ResponseField>

<ResponseField name="GetBancos" type="array">
  Available banks for selection
</ResponseField>

<ResponseField name="GetBancosCredito" type="array">
  Candidate's bank accounts
</ResponseField>

<ResponseField name="GetCreditos" type="array">
  Credit cards and loans
</ResponseField>

<ResponseField name="GetInmuebles" type="array">
  Real estate properties
</ResponseField>

<ResponseField name="GetModelos" type="array">
  Available vehicle models
</ResponseField>

<ResponseField name="GetMuebles" type="array">
  Personal property and vehicles
</ResponseField>

<ResponseField name="GetIngresosExtras" type="array">
  Additional income sources
</ResponseField>

## Save Economic Data

<api method="POST" path="/SaveEconomicos" />

Saves income and expense information.

### Request Body

<ParamField body="evalID" type="string" required>
  Evaluation ID
</ParamField>

#### Income Information

<ParamField body="economicosMensual" type="number" required>
  Monthly base salary/income
</ParamField>

<ParamField body="economicosAdicional" type="number">
  Additional income amount
</ParamField>

<ParamField body="economicosConsiste" type="text">
  Description of what additional income consists of
</ParamField>

<ParamField body="economicosTotalIngreso" type="number" required>
  Total monthly income
</ParamField>

#### Expense Categories

<ParamField body="economicosAlimentos" type="number" required>
  Food expenses
</ParamField>

<ParamField body="economicosTransporte" type="number" required>
  Transportation expenses
</ParamField>

<ParamField body="economicosServicios" type="number" required>
  Utilities (water, electricity, gas, etc.)
</ParamField>

<ParamField body="economicosComunicaciones" type="number" required>
  Phone, internet, communications
</ParamField>

<ParamField body="economicosTarjetas" type="number" required>
  Credit card payments
</ParamField>

<ParamField body="economicosCreditos" type="number" required>
  Loan payments
</ParamField>

<ParamField body="economicosVestido" type="number" required>
  Clothing expenses
</ParamField>

<ParamField body="economicosMedico" type="number" required>
  Medical/health expenses
</ParamField>

<ParamField body="economicosTandas" type="number" required>
  Savings circles (tandas)
</ParamField>

<ParamField body="economicosAhorros" type="number" required>
  Savings contributions
</ParamField>

<ParamField body="economicosEscolares" type="number" required>
  School/education expenses
</ParamField>

<ParamField body="economicosRenta" type="number" required>
  Rent or mortgage payment
</ParamField>

<ParamField body="economicosPension" type="number" required>
  Pension or alimony payments
</ParamField>

<ParamField body="economicosFaltante" type="number" required>
  Other/miscellaneous expenses
</ParamField>

<ParamField body="economicosTotalEgresos" type="number" required>
  Total monthly expenses
</ParamField>

#### Property Information

<ParamField body="economicosTipo" type="string" required>
  Type of residence ("Propia", "Rentada", "Familiar")
</ParamField>

<ParamField body="economicosRegimen" type="string" required>
  Property regime if married ("Sociedad Conyugal", "Separación de Bienes")
</ParamField>

<ParamField body="economicosProblematica" type="text">
  Any economic problems or issues
</ParamField>

### Response

<ResponseField name="success" type="string">
  "Se guardaron economicos correctamente !" - Economic data saved successfully
</ResponseField>

  "economicosMensual": 15000,
  "economicosAdicional": 2000,
  "economicosConsiste": "Trabajo independiente fines de semana",
  "economicosTotalIngreso": 17000,
  "economicosAlimentos": 4000,
  "economicosTransporte": 1500,
  "economicosServicios": 800,
  "economicosComunicaciones": 600,
  "economicosTarjetas": 1000,
  "economicosCreditos": 2000,
  "economicosVestido": 500,
  "economicosMedico": 800,
  "economicosTandas": 500,
  "economicosAhorros": 1000,
  "economicosEscolares": 2000,
  "economicosRenta": 3000,
  "economicosPension": 0,
  "economicosFaltante": 500,
  "economicosTotalEgresos": 18200,
  "economicosTipo": "Rentada",

## Workflow

1. Retrieve existing economic data using GET endpoint
2. Save or update main economic data (income/expenses)
3. Add bank accounts
4. Add credits/loans
5. Add real estate properties
6. Add personal property (vehicles, etc.)
7. Add additional income sources
8. Delete records as needed

## Best Practices

- Ensure total income equals the sum of base salary and additional income
- Total expenses should equal the sum of all expense categories
- Update bank account balances regularly
- Include all debts and liabilities
- Document all significant assets
- Verify all financial information is accurate and current
